# u_URLblock (Time Keeper & URL Blocker)

*Read this in other languages: [English](README.en.md), [日本語](../README.md), [简体中文](README.zh-CN.md).*

这是一款本地应用程序，用于限制您在 PC 上的网站浏览时间，并强力阻止访问特定网站（例如社交媒体和成人网站）。

## ✨ 特点
- **时间限制功能**：可以限制特定网站（如 YouTube、X(Twitter)、Instagram、TikTok 等）每天的访问时间（秒）。
- **完全拦截功能**：强制拦截对指定域名的访问（如成人网站或容易让人分心的网站）。
- **规避任务管理器**：该应用程序伪装成 Windows 系统进程（如 `AudioDG_helper.exe` 或 `WinLogonAssist.exe`）在后台运行，防止其被轻易强制结束（杀后台）。
- **便携环境**：在 `bin` 文件夹内自动构建独立的 Python 环境，无需在电脑上安装 Python，保持环境纯净。
- **深色模式 UI**：直观且时尚的深色模式 GUI，可查看今日剩余时间及黑名单列表。

## 🚀 安装方法

1. 将此仓库以 ZIP 格式下载，并解压到任意位置。
2. 双击文件夹中的 `setup.bat` 运行。
3. （将自动构建便携版 Python 环境、安装必要的依赖库及 UI 组件，请稍候。）
4. 当显示“请按任意键继续...”时，说明安装已完成！

## 💻 使用方法

1. 双击 `run.bat` 启动。
2. 屏幕边缘将显示一个小的悬浮窗口（Time Keeper），开始对各个网站的剩余时间进行倒计时。
3. 如果您尝试打开已超过时间限制的网站，或黑名单中记录的网站，访问将被自动拦截。
4. 每次重启电脑后，请再次运行 `run.bat`。

## ⚙️ 修改设置 (config.json)

您可以使用文本编辑器（如记事本）打开并编辑自带的 `config.json`，以修改拦截的网站或时间限制。

```json
{
    "WHITE_LIST": [
        "chiebukuro.yahoo.co.jp"
    ],
    "TIME_LIMITS": {
        "youtube.com": 1800,  // 将 YouTube 限制为每天 30 分钟 (1800 秒)
        "x.com": 180          // 将 X(Twitter) 限制为每天 3 分钟 (180 秒)
    },
    "BLOCK_LIST": [
        "example-bad-site.com" // 完全禁止访问的网站
    ]
}
```
* 编辑后，重启应用程序（或结束进程后再次运行 `run.bat`）即可生效。

## ⚠️ 注意事项与技术说明
- 由于该应用使用了系统进程监控等技术，可能会被部分杀毒软件误报。如遇此情况，请将其加入白名单/排除项。
- 如果您希望完全退出应用，必须从任务管理器中手动结束 `AudioDG_helper.exe`、`FontHost_worker.exe`、`SpoolerSub_helper.exe` 和 `WinLogonAssist.exe`（此为设计机制）。
- **关于虚拟桌面（后台桌面）的说明**：
  - 本应用会枚举并监控 Windows 中所有可见窗口。因此，**在当前未显示的另一个虚拟桌面（后台桌面）中打开的浏览器标签页，同样会被纳入监控范围**。
  - **时间计算**：如果您将受限网站（如 YouTube）放在虚拟桌面中保持打开状态，即使您没有观看，剩余时间也会持续消耗。不使用时请务必关闭标签页。
  - **强制拦截**：如果您在虚拟桌面中打开了被屏蔽的网站，系统也会在后台向该进程发送强制关闭指令，标签页会被无情关闭。

## 🛡️ 终极自律设置（利用管理员权限进行强力拦截）

为了让这款应用成为“毫无漏洞”的终极工具，我们建议您将 Windows 的管理员权限（Administrator）与标准用户分开使用。

### 设置原理与优势
1. **分离用户账户**：平时使用的账户设为“标准用户”，管理用账户设为“Administrator”。
2. **限制修改权限**：将 `config.json` 的编辑权限以及应用文件的修改权限仅授予 Administrator。
   - ⚠️ **重要提示**：由于应用需要记录日志和状态，请**务必**保留标准用户（如 Authenticated Users）对 `authenticated_users_kakikomi_true` 文件夹的“写入”权限（否则应用无法正常运行）。
3. **防止杀后台**：即使尝试从任务管理器强制结束本应用的进程，标准用户也会因为没有 Administrator 权限而无法关闭它。
4. **100 位密码**：将 Administrator 的密码设置为一串极长（如 100 位）的随机字符。（请保存在密码管理器中，或写在纸上封存）。
   这样一来，每当您脑海中浮现“我好想超时看 YouTube”的念头时，都必须手动输入 100 位的密码才能解除限制，这将成为极强的威慑力。
5. **结合 Microsoft Family Safety 使用**：通过同时使用 Windows 自带的“Microsoft Family Safety”功能，可以为该应用（或浏览器本身）设置“可用时间段”或“每日总使用时间”，从而在操作系统级别实施更严密的双重限制。

### 任务计划程序注册步骤（以最高特权运行）
在任务计划程序中注册，以便标准用户登录时，应用能以 Administrator（最高权限）在后台自动启动。

1. **使用 Administrator 账户登录 Windows**。
2. 在开始菜单的搜索栏中搜索并打开“任务计划程序”。
3. 在右侧的操作面板中点击“创建任务...”（※注意：不是“创建基本任务”）。
4. **[常规] 选项卡**：
   - 名称：输入一个易于识别的名称，例如 `u_URLblock_Start`。
   - 安全选项：选择“不管用户是否登录都要运行”。
   - 勾选“使用最高权限运行”。
5. **[触发器] 选项卡**：
   - 点击“新建”，将开始任务设置为“登录时”。
   - 选择“特定用户”，并指定您平时使用的**标准用户**账户。
6. **[操作] 选项卡**：
   - 点击“新建”，将操作设置为“启动程序”。
   - 程序或脚本：指定 `run.bat` 的完整路径（例如：`C:\path\to\u_URLblock\run.bat`）。
   - 起始于(可选)：输入 `run.bat` 所在的文件夹路径（例如：`C:\path\to\u_URLblock`）。
7. **[条件] / [设置] 选项卡**：
   - 如果您使用的是笔记本电脑，可根据需要在 [条件] 选项卡中取消勾选“只有在计算机使用交流电源时才启动此任务”。
8. 点击“确定”保存。此时系统会要求输入 Administrator 的密码，请输入。

设置完成后，当您以标准用户身份登录时，该应用将自动以最高权限（Administrator 权限）启动。
这样，标准用户既无法修改设置，也无法通过任务管理器强制关闭进程，最强自律环境就此诞生。
