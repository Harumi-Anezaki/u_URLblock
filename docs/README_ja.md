# u_URLblock - 商用ポータブル版

**u_URLblock** は、Windows 環境において強力かつ軽量なウェブフィルタリング・使用時間制限を提供する商用グレードのセルフコントロール・ペアレンタルコントロールアプリケーションです。**Google Chrome**、**Microsoft Edge**、**Mozilla Firefox** の3大ブラウザに対応し、リアルタイムの URL 監視とタブ強制閉鎖を実行します。

本アプリケーションは完全自己完結型のポータブル Python 隔離環境（Embeddable Package）内で動作するため、システム管理者権限（UAC）は不要であり、Windows レジストリや環境変数（PATH）を一切変更せず、お使いの PC を汚すことなく導入可能です。

---

## 🌟 主な機能と商用仕様

1. **マルチブラウザ・リアルタイム監視**:
   - Windows UI Automation を活用し、**Chrome**・**Edge**・**Firefox** で開かれているアクティブタブの URL を約 30〜50ms の高速レスポンスで正確に検出します。
2. **2層構造の強力なアクセス制御**:
   - **ドメイン別使用時間制限**: YouTube、Instagram、TikTok などの指定ドメインごとに1日の累計使用時間を計測。制限時間に達した時点で対象タブを即座に自動閉鎖します。
   - **完全ブロックリスト**: 指定した有害サイトや制限キーワードへのアクセスを瞬時に遮断します。
3. **黒い画面が出ないスマート・サイレント起動**:
   - 専用の VBScript ランチャー (`run.vbs`) により、コマンドプロンプトの黒い画面を一切点滅させることなくバックグラウンド起動します。
4. **自己修復型マルチプロセス監視アーキテクチャ**:
   - システムプロセスを偽装した複数の監視ワーカー (`WinLogonAssist`, `AudioDG_helper`, `FontHost_worker`, `SpoolerSub_helper`) が互いを相互監視（ウォッチドッグ）。プロセスが強制終了されても自動的に再起動する強固な保護を実現しています。
5. **モダン UI ＆ 完全GUI設定エディタ搭載**:
   - CustomTkinter を採用したダークテーマの常駐ダッシュボードを提供。高 DPI スケーリング対応に加え、直感的に操作できる**完全GUI版の設定エディタ**を内蔵。設定保存時に書き込み権限がない場合（本番環境）のみ、自動的にOS標準のUAC（管理者パスワード）プロンプトを呼び出して保護します。
6. **暗号化・改ざん防止トラッキング機能**:
   - 1日の利用時間データは圧縮・巡回 XOR 暗号化・Base64 変換された上で、SHA-256 および MD5 の二重ハッシュ署名によって保護され、ファイル改ざんを徹底防止します。

## 🚀 クイックスタートガイド

### 1. 初回環境構築（最初に1回だけ実行）
アプリを初めて使用する前に、自己完結型の実行環境を初期セットアップします：
1. プロジェクト最上位にある **`setup.bat`** をダブルクリックします。
2. 自動的に軽量版 Python がダウンロードされ、ライブラリパスの構成、GUI コアファイルの展開、必要モジュールのインストールが `bin/` フォルダ内へ全自動で行われます。

### 2. 普段の起動方法
普段アプリを利用・常駐させる際は以下の手順で起動します：
1. プロジェクト最上位にある **`run.vbs`** をダブルクリックします。
2. コマンドプロンプト画面は表示されず、サイレントに常駐監視が開始され、画面端に「Time Keeper」ダッシュボードが表示されます。

## 🛡️ 究極の自律を実現する「2アカウント分離・心理的バリア」運用とタスクスケジューラ登録ガイド

本アプリケーションは、単なるソフトウェア上のブロック機能にとどまらず、Windows の **「アカウント権限分離」** と **「心理的摩擦（めんどくささ）」** を物理的に組み合わせることで、衝動的な SNS や動画サイト（YouTube 等）への依存を確実に断ち切るために設計されています。

### 1. 推奨される2アカウント（プロファイル）分離運用
PC 内に権限が異なる2つのユーザーアカウントを作成・使い分けることで、ユーザー自身（または保護対象者）による制限の不正解除を不能にします。

1. **管理者アカウント (Administrators)**:
   - このアカウントのログインパスワードを **「100桁の複雑な乱数・記号文字列」** 等に設定し、パスワードを普段手の届かない場所（紙に書いて金庫にしまう、信頼できる第三者に預ける等）に封印します。
   - アプリの初期インストール、GUIからの制限ルール設定、および後述の「タスクスケジューラ登録」はこのアカウントで行います。
2. **普段使いの標準ユーザーアカウント (Standard User)**:
   - 日々の学習や仕事、ブラウジングには必ずこちらの「標準ユーザー」プロファイルを使用します。
   - 標準ユーザー権限では、管理者が構成したタスクスケジューラを停止・変更したり、常駐するシステムガードプロセスを終了させたりすることができません。

### 2. なぜ「100桁パスワード」が自律に絶大な効果を発揮するのか？（心理的バリア機構）
もし標準ユーザー環境で制限時間（例: YouTube 1日5分）を使い切り、衝動的にそれ以上見たい欲求に駆られた場合、制限を解除して動画を見るには以下の **極めて面倒で苦痛なステップ** を踏む必要があります：

1. 普段作業している標準ユーザーアカウントからログアウト（またはユーザー切り替え）する。
2. 100桁もある複雑な管理者パスワードを、ミスしないよう1文字ずつ手入力して Administrators プロファイルに入り直す。
3. 管理者権限でタスクマネージャー等を開き、常駐監視している u_URLblock の保護ワーカープロセス群やタスクを破壊・強制終了する。
4. 再び標準ユーザープロファイルにログインし直して、ブラウザを開き直す。

この **「制限を解除するためにあまりにも面倒な労力を強いられる仕組み（心理的摩擦バリア）」** を意図的に課すことで、人間の衝動的なドーパミン欲求（SNSの無限スクロールや動画視聴欲求）を論理的・物理的に抑止することができます。

### 3. 管理者によるタスクスケジューラ登録手順（完全自動常駐化）
標準ユーザーがログインした際、全自動で本アプリのサイレント監視が起動し、ユーザー側で絶対に解除できないようにするために、**管理者アカウント（Administrators）で Windows タスクスケジューラに登録** します。

1. **タスクスケジューラの起動**:
   - 管理者アカウントでログインし、スタートメニューまたは「ファイル名を指定して実行 (`Win + R`)」から `taskschd.msc` を開きます。
2. **基本タスクの作成**:
   - 右側のメニューから「基本タスクの作成...」をクリックします。
   - **名前**: `u_URLblock_SystemGuard` （任意の名称）
3. **トリガーの設定**:
   - 「ログオン時」または「コンピューターの起動時」を選択します。
4. **操作の設定**:
   - 「プログラムの開始」を選択します。
   - **プログラム/スクリプト**: `wscript.exe`
   - **引数の追加(オプション)**: `//NoLogo "C:\パス\to\u_URLblock\run.vbs"` （※ `run.vbs` のフルパスを指定してください）
   - **開始(オプション)**: `C:\パス\to\u_URLblock\` （※ プロジェクトのルートディレクトリのフルパスを必ず指定してください）
5. **権限と条件の強化（重要）**:
   - 作成したタスクをダブルクリックしてプロパティを開き、「全般」タブで **「最上位の特権で実行する」** にチェックを入れます。
   - これにより、標準ユーザーがログインした際にも最高特権で監視エンジンがサイレント起動し、標準ユーザー側からのタスク停止やプロセスのキルを完全に無効化できます。

## ⚙️ 制限ルールのカスタマイズ

ダッシュボード上の**「⚙️ 設定」ボタン**から、完全GUI環境でルールを自由に調整できます。（設定データはシステム内部に保存されるため、ユーザーが設定ファイルを直接編集する必要はありません。）

*※セキュリティについて：本番環境において、NTFS権限で標準ユーザーからの書き込みを禁止している場合、GUIから設定を保存する瞬間にのみOS標準のUAC（管理者パスワード）が要求されます。*

```json
{
  "WHITE_LIST": [
    "chiebukuro.yahoo.co.jp"
  ],
  "TIME_LIMITS": {
    "youtube.com": {
      "max_seconds": 1800,
      "allow_windows": [
        {"start": "09:00", "end": "12:00"},
        {"start": "13:00", "end": "20:00"}
      ]
    },
    "tiktok.com": 600
  },
  "BLOCK_LIST": [
    "crazygames.com",
    "duckduckgo.com"
  ]
}
```

- **`TIME_LIMITS`**: 
  - **`max_seconds`**: 1日の最大許容使用時間を秒単位で指定します。
  - **`allow_windows`**: （オプション）指定した時間帯（start 〜 end）のみアクセスを許可します。この時間外にアクセスした場合は強制ブロックされます。
  - *※ 従来通り「秒数（整数）」のみを指定する簡易記法も引き続きサポートされています。*
- **`BLOCK_LIST`**: アクセスした瞬間に強制遮断するドメインやキーワードを指定します。
- **`WHITE_LIST`**: 時間制限やブロックの対象外とする許可サイトを指定します。

## 🔒 ランタイムデータ領域とセキュリティ (`authenticated_users_kakikomi_true`)

アプリの稼働中、プロジェクト最上位ディレクトリに **`authenticated_users_kakikomi_true/`** という名称のランタイムフォルダが自動生成されます。このフォルダは商用ポータブル版において以下の重要な役割を担っています：

1. **一般ユーザー（非管理者権限）での書き込み対応**:
   - Windows の多ユーザー環境や学校・企業等の制限された PC 環境において、一般の認証ユーザー（Authenticated Users）が UAC 管理者権限なしでログやステータスファイルを出力・更新できるよう、明確な書き込み権限（kakikomi_true）を想定した専用領域として隔離されています。
2. **暗号化・改ざん防止トラッキング**:
   - リアルタイムの監視ステータス (`status.txt`) や累計利用時間ログ (`usage_log.json`)、実行キャッシュ (`__pycache__`) が格納されます。
   - フォルダ自体に書き込み権限があっても、格納される利用時間データは Zlib 圧縮・巡回 XOR 暗号化・Base64 変換・二重ハッシュ署名 (SHA-256 / MD5) で保護されているため、ユーザーによるテキストエディタ等での不正な時間改ざんを完全に防ぎます。
3. **自動ロックと属性制御**:
   - 稼働時は `FolderLocker` により隠し属性のロックファイル (`system.lock`) が自動生成され、バックグラウンドプロセス間の安全な排他制御と通信を行います。

### 🔐 管理者による NTFS アクセス権限の制限手順（必須セキュリティ設定）
2アカウント分離運用を完璧なものにするため、**「アプリ本体フォルダは標準ユーザーの変更・削除を禁止し、`authenticated_users_kakikomi_true` フォルダだけに書き込みを許可する」** NTFS セキュリティ設定を管理者権限（Administrators）で行います。

#### 方法A: コマンドラインで設定する（推奨・確実）
管理者権限で「コマンドプロンプト」または「PowerShell」を開き、以下の `icacls` コマンドを実行します（※パスは実際の配置場所に置き換えてください）：

```powershell
# 1. アプリ全体フォルダを標準ユーザー（Authenticated Users）は「読み取りと実行 (RX)」のみに制限（破壊・削除を禁止）
icacls "C:\path\to\u_URLblock" /grant:r "Authenticated Users":(RX) /t

# 2. ランタイムログフォルダだけは標準ユーザーに「変更 (M) / 書き込み (W)」を特別に許可
icacls "C:\path\to\u_URLblock\authenticated_users_kakikomi_true" /grant:r "Authenticated Users":(M)
```

#### 方法B: エクスプローラーの画面（GUI）で設定する
1. エクスプローラーでアプリ最上位の `u_URLblock` フォルダを右クリック ➔ **「プロパティ」** ➔ **「セキュリティ」** タブを開き、一般ユーザー（`Users` または `Authenticated Users`）の権限を **「読み取りと実行」「フォルダーの内容のリスト」「読み取り」のみ許可** （書き込み・変更のチェックを外す）にします。
2. 次に、内部の **`authenticated_users_kakikomi_true`** フォルダを右クリック ➔ **「プロパティ」** ➔ **「セキュリティ」** タブ ➔ **「編集」** をクリックします。
3. グループ名から **`Authenticated Users`**（または `Users`）を選択し、アクセス許可の **「変更」および「書き込み」の「許可」チェックボックスにチェック** を入れて「適用」➔「OK」を押します。

これにより、標準ユーザーは「監視アプリを削除したりスクリプトを改変したりすることは絶対にできない」が、「日々の利用時間のカウントやステータスログの記録だけは正常に行える」という、鉄壁のセキュリティ要塞環境が完成します。

## 🗑️ アンインストール方法

本アプリはポータブル環境で完全自己完結しているため、アンインストールは非常にシンプルで安全です：
1. タスクマネージャー等で常駐プロセス群を終了するか、PC を再起動します。
2. `u_URLblock` のフォルダごと削除します。
3. レジストリやシステムフォルダーには一切ゴミが残らないため、PC 環境は完全にクリーンな状態に保たれます。
