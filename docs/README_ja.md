# u_URLblock - 商用ポータブル版

**u_URLblock** は、Windows 環境において強力かつ軽量なウェブフィルタリング・使用時間制限を提供する商用グレードのセルフコントロール・ペアレンタルコントロールアプリケーションです。**Google Chrome**、**Microsoft Edge**、**Mozilla Firefox** の3大ブラウザに対応し、リアルタイムの URL 監視とタブ強制閉鎖を実行します。

本アプリケーションは完全自己完結型のポータブル Python 隔離環境（Embeddable Package）内で動作するため、システム管理者権限（UAC）は不要であり、Windows レジストリや環境変数（PATH）を一切変更せず、お使いの PC を汚すことなく導入可能です。

---

## 🌟 主な機能と商用仕様

1. **マルチブラウザ・リアルタイム監視**:
   - Windows UI Automation を活用し、**Chrome**・**Edge**・**Firefox** で開かれているアクティブタブの URL を約 30〜50ms の高速レスポンスで正確に検出します。
2. **2層構造の強力なアクセス制御**:
   - **ドメイン別使用時間制限**: YouTube、Instagram、TikTok などの指定ドメインごとに1日の累計使用時間を計測。制限時間に達した時点で対象タブを即座に自動閉鎖します。
   - **完全ブロックリスト**: 指定した有害サイトや制限キーワードへのアクセスを瞬時に遮断します。
3. **黒い画面が出ないスマート・サイレント起動**:
   - 専用の VBScript ランチャー (`run.vbs`) により、コマンドプロンプトの黒い画面を一切点滅させることなくバックグラウンド起動します。
4. **自己修復型マルチプロセス監視アーキテクチャ**:
   - システムプロセスを偽装した複数の監視ワーカー (`WinLogonAssist`, `AudioDG_helper`, `FontHost_worker`, `SpoolerSub_helper`) が互いを相互監視（ウォッチドッグ）。プロセスが強制終了されても自動的に再起動する強固な保護を実現しています。
5. **モダン UI ＆ 高解像度 (DPI) スケーリング対応**:
   - CustomTkinter を採用したダークテーマの常駐ダッシュボードを提供。高 DPI スケーリング対応 (`SetProcessDpiAwareness`) により、4K ディスプレイや高倍率設定でも文字ボケしない鮮明な描画を維持します。
6. **暗号化・改ざん防止トラッキング機能**:
   - 1日の利用時間データは圧縮・巡回 XOR 暗号化・Base64 変換された上で、SHA-256 および MD5 の二重ハッシュ署名によって保護され、ファイル改ざんを徹底防止します。

## 🚀 クイックスタートガイド

### 1. 初回環境構築（最初に1回だけ実行）
アプリを初めて使用する前に、自己完結型の実行環境を初期セットアップします：
1. プロジェクト最上位にある **`setup.bat`** をダブルクリックします。
2. 自動的に軽量版 Python がダウンロードされ、ライブラリパスの構成、GUI コアファイルの展開、必要モジュールのインストールが `bin/` フォルダ内へ全自動で行われます。

### 2. 普段の起動方法
普段アプリを利用・常駐させる際は以下の手順で起動します：
1. プロジェクト最上位にある **`run.vbs`** をダブルクリックします。
2. コマンドプロンプト画面は表示されず、サイレントに常駐監視が開始され、画面端に「Time Keeper」ダッシュボードが表示されます。

## ⚙️ 設定ファイル (`config.json`) のカスタマイズ

プロジェクト最上位にある **`config.json`** をテキストエディタで開くことで、ブロックルールや制限時間を自由に調整できます：

```json
{
  "WHITE_LIST": [
    "chiebukuro.yahoo.co.jp"
  ],
  "TIME_LIMITS": {
    "instagram.com": 180,
    "x.com": 180,
    "youtube.com/shorts": 180,
    "tiktok.com": 600,
    "youtube.com": 1800
  },
  "BLOCK_LIST": [
    "crazygames.com",
    "streamtape.com",
    "duckduckgo.com"
  ]
}
```

- **`TIME_LIMITS`**: ドメイン名と1日の最大許容使用時間を **秒単位** で指定します（例: `1800` = 30分）。
- **`BLOCK_LIST`**: アクセスした瞬間に強制遮断するドメインやキーワードを指定します。
- **`WHITE_LIST`**: 時間制限やブロックの対象外とする許可サイトを指定します。

## 🗑️ アンインストール方法

本アプリはポータブル環境で完全自己完結しているため、アンインストールは非常にシンプルで安全です：
1. タスクマネージャー等で常駐プロセス群を終了するか、PC を再起動します。
2. `u_URLblock` のフォルダごと削除します。
3. レジストリやシステムフォルダーには一切ゴミが残らないため、PC 環境は完全にクリーンな状態に保たれます。

## 📁 ディレクトリ構成

```text
u_URLblock/
 ├─ setup.bat          # 初回自動環境構築スクリプト
 ├─ run.vbs            # 普段のサイレント起動用ランチャー
 ├─ config.json        # ユーザー設定ファイル（制限ルール）
 ├─ README.md          # 英語版マニュアル
 ├─ docs/              # 多言語マニュアルフォルダ
 │   ├─ README_ja.md   # 日本語版マニュアル（本書）
 │   └─ README_zh.md   # 中国語版マニュアル
 ├─ bin/               # 自動生成される軽量版 Python 本体 (隔離領域)
 └─ core/              # ユーザーには見せない内部ソースコード群
     ├─ main.pyw       # アプリ統括・ウォッチドッグ起動スクリプト
     ├─ data_manager.py # 暗号化ログ管理・設定ロードモジュール
     ├─ ui.py          # CustomTkinter DPI対応 GUI モジュール
     ├─ monitor.pyw    # マルチブラウザ リアルタイム URL 監視エンジン
     ├─ watcher.pyw    # プロセス死活監視・自動再起動ワーカー
     ├─ system_guard.pyw # WMI/Mutex システムガード
     └─ win_utils.py   # Windows API 制御ユーティリティ
```
