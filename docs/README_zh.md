# u_URLblock - 商业便携版 (Commercial Portable Edition)

**u_URLblock** 是一款适用于 Windows 平台的商业级高级网络过滤与时间管理应用程序，旨在为您提供高效的上网自律与家长控制解决方案。全面支持 **Google Chrome**（谷歌浏览器）、**Microsoft Edge** 以及 **Mozilla Firefox**（火狐浏览器）三大主流浏览器，提供毫秒级实时 URL 监控与选项卡自动关闭功能。

本软件运行于完全独立、自包含的便携式嵌入式 Python 环境（Embeddable Package）中，无需系统管理员权限（UAC），不修改任何 Windows 注册表项，不污染系统全局环境变量（PATH），实现真正意义上的绿色环保免安装。

---

## 🌟 核心功能与商业特性

1. **多浏览器实时精准监控**:
   - 采用 Windows UI Automation 核心技术，实时捕捉 **Chrome**、**Edge** 及 **Firefox** 中当前活动标签页的 URL 地址，响应速度极快（约 30~50 毫秒）。
2. **双层防护过滤机制**:
   - **每日时长限制**: 针对指定网站（如 YouTube、Instagram、TikTok 等）计算每日累计浏览时间，超时后即刻强制关闭对应网页标签。
   - **绝对黑名单**: 针对预设的不良网页域名或敏感关键词，一旦检测到访问将瞬间拦截并强行关闭窗口。
3. **静默智能启动脚本**:
   - 专属 VBScript 启动器 (`run.vbs`)，在日常开机或运行软件时完全隐藏命令行黑框，实现真正的后台无感运行。
4. **自愈式多进程相互守护架构**:
   - 采用伪装成 Windows 系统服务的后台进程组 (`WinLogonAssist`, `AudioDG_helper`, `FontHost_worker`, `SpoolerSub_helper`) 进行多进程互保（Watchdog）。即使某个进程被意外终止，也能在 1 秒内自动复活，确保防御固若金汤。
5. **现代化 UI 与高DPI缩放支持**:
   - 采用 CustomTkinter 构建科技感十足的深色悬浮仪表盘。内置 **高 DPI 缩放感知** (`SetProcessDpiAwareness`)，在 4K 高分辨率或高缩放显示器上依然保持字体锐利清晰，拒绝模糊。
6. **防篡改加密追踪引擎**:
   - 每日的使用时长数据均经过 Zlib 压缩、循环 XOR 加密以及 Base64 编码，并搭载 SHA-256 与 MD5 双重加密签名核实，彻底杜绝手动修改日志作弊。

## 🛡️ 双账号隔离与心理阻力自律架构 (Dual-Account Isolation & Psychological Friction)

本应用程序的设计核心不仅在于纯粹的软件拦截，更是通过将 Windows 的 **“账号权限物理隔离”** 与 **“心理摩擦力（极度麻烦的阻力）”** 完美结合，从根本上根除冲动性刷视频与社交网络成瘾（如 YouTube、TikTok、Instagram 等）。

### 1. 推荐的双账号（配置档案）隔离部署指南
在您的 PC 操作系统上部署权限分立的两个账户，可彻底杜绝终端用户（或处于自律薄弱期的自己）非法越权解除上网限制：

1. **系统管理员账号 (Administrators)**:
   - 将此管理员账号的登录密码修改为 **“长度高达 100 位的超复杂随机密码”**，并将该密码物理封存或隐藏（如写在纸上锁进保险箱、托付给信赖的亲友或保存于复杂的密码管理器中）。
   - 该账号仅限于进行应用首次配置、修改 `config.json` 监控规则以及下文所述的“任务计划程序”后台驻留注册。
2. **日常普通用户账号 (Standard User)**:
   - 终端用户的日常学习、工作与娱乐上网均严格在受限的 **“普通标准用户”** 配置档案下进行。
   - 在普通用户权限下，无法在任务管理器中终止被守护的监控进程组，亦无法修改或停止系统管理员设定的任务计划，真正做到防篡改。

### 2. 为什么“100位超长密码”对自律防沉迷具有奇效？（心理摩擦力机制）
当普通账号下的每日浏览限制（例如 YouTube 每日 5 分钟）用尽，此时由于冲动和多巴胺驱动想要继续看视频时，若想解除限制继续观看，用户必须经历以下 **极其繁琐、耗时且痛苦的物理操作流程**：

1. 退出或切换当前的日常标准用户账号。
2. 面对 Windows 登录界面，手动、一字不差地敲打输入长达 100 位的超复杂管理员密码以进入 Administrators 档案。
3. 调出系统管理员权限的任务管理器，强行杀死或破坏常驻后台监控的 `u_URLblock` 守护进程与任务计划。
4. 再次切换或登录回普通标准账号，重新打开浏览器。

这套 **“为了看几分钟视频需要折腾半个多小时的繁琐机制（高心理阻力屏障）”** 能够直接掐断大脑中冲动刷屏的奖励回路，使人在输入密码的繁琐过程中冷静下来，进而主动放弃违规上网，实现终极的戒断与自律。

### 3. 管理员配置系统任务计划程序教程（彻底自动化驻留）
为了确保普通账号一开机登录就全自动静默加载监控，且用户绝对无法绕过，请通过 **Administrators 账号在 Windows 任务计划程序中注册自启任务**：

1. **启动任务计划程序**:
   - 在管理员账号下，按 `Win + R` 输入 `taskschd.msc` 并回车。
2. **创建基本任务**:
   - 点击右侧操作栏中的 **“创建基本任务...”**。
   - **名称**: `u_URLblock_SystemGuard` （可自定义名称）。
3. **设置触发器**:
   - 选择 **“当用户登录时”** 或 **“计算机启动时”**。
4. **设置操作**:
   - 选择 **“启动程序”**。
   - **程序/脚本**: `wscript.exe`
   - **添加参数(可选)**: `//NoLogo "C:\路径\to\u_URLblock\run.vbs"` （*请将其替换为您电脑中 run.vbs 的绝对路径*）。
   - **起始于(可选)**: `C:\路径\to\u_URLblock\` （*必填项：请将其替换为本项目根目录的绝对路径*）。
5. **最高特权与条件强化（核心关卡）**:
   - 双击创建好的任务打开“属性”，在“常规”选项卡中勾选 **“使用最高权限运行”**。
   - 这确保了即使是在权限较低的标准用户登录环境中使用，后台监控与守护进程也始终持有至高无上的管理员特权，普通用户试图关闭后台的任何尝试都将被系统无情拒绝。

## ⚙️ 规则配置 (`config.json`)

通过使用文本编辑器打开根目录下的 **`config.json`**，您可以自由定制监控规则与限制时长：

```json
{
  "WHITE_LIST": [
    "chiebukuro.yahoo.co.jp"
  ],
  "TIME_LIMITS": {
    "instagram.com": 180,
    "x.com": 180,
    "youtube.com/shorts": 180,
    "tiktok.com": 600,
    "youtube.com": 1800
  },
  "BLOCK_LIST": [
    "crazygames.com",
    "streamtape.com",
    "duckduckgo.com"
  ]
}
```

- **`TIME_LIMITS`**: 配置域名及其每日最高允许浏览时间，单位为 **秒**（例如：`1800` 代表 30 分钟）。
- **`BLOCK_LIST`**: 配置一旦访问即被永久封锁并关闭的网页域名或关键词。
- **`WHITE_LIST`**: 白名单规则，访问此类域名将不计入时长且不被拦截。

## 🔒 运行时数据目录与安全性 (`authenticated_users_kakikomi_true`)

在应用程序运行期间，系统会在项目根目录下自动生成名为 **`authenticated_users_kakikomi_true/`** 的运行时目录。该目录在架构与安全防御层面具有举足轻重的作用：

1. **普通用户（非管理员）读写支持**:
   - 在 Windows 多用户环境、学校或企业受限 PC 中，普通认证用户（Authenticated Users）无需系统管理员权限（UAC 提示）即可在该隔离区域内存取运行日志与状态文件（名称对应日语“允许写入”）。
2. **加密与防篡改日志保护**:
   - 该目录用于存放实时监控状态 (`status.txt`)、每日累计时长日志 (`usage_log.json`) 以及 Python 运行缓存 (`__pycache__`)。
   - 尽管普通用户对该目录具有写入权限，但底层的时长数据均经过 Zlib 压缩、循环 XOR 加密、Base64 编码，并由 SHA-256 与 MD5 双重加密签名严密保护。任何手动修改尝试将立即触发数据校验失败与超时惩罚机制。
3. **自动锁定与隐藏属性**:
   - 运行时会自动生成隐藏系统锁文件 (`system.lock`)，确保多进程后台守护程序之间的安全通信与文件排他互斥。

### 🔐 管理员配置 NTFS 访问权限限制教程（必备安全设定）
为了让“双账号隔离防御体系”坚不可摧，必须由管理员账号（Administrators）在系统底层设定 NTFS 文件夹权限：**严禁普通标准用户修改或删除应用整体文件，仅向其开放 `authenticated_users_kakikomi_true` 目录的写入权限**。

#### 方法 A: 使用命令行 / `icacls` 配置（推荐，高效快捷）
以管理员身份运行“命令提示符(CMD)”或“PowerShell”，并执行以下命令（*请将其中的路径替换为您电脑里的实际路径*）：

```powershell
# 1. 将应用根目录及所有子文件的“认证用户(Authenticated Users)”权限限制为仅“读取和执行 (RX)”（杜绝程序被恶意修改或删除）
icacls "C:\path\to\u_URLblock" /grant:r "Authenticated Users":(RX) /t

# 2. 仅针对运行时日志文件夹，向普通认证用户开放“修改 (M) 和 写入 (W)”权限
icacls "C:\path\to\u_URLblock\authenticated_users_kakikomi_true" /grant:r "Authenticated Users":(M)
```

#### 方法 B: 使用资源管理器图形界面 (GUI) 配置
1. 在资源管理器中右键点击顶层的 `u_URLblock` 文件夹 ➔ **“属性”** ➔ **“安全”** 选项卡。将普通用户组（`Users` 或 `Authenticated Users`）的权限设置为仅勾选 **“读取和执行”、“列出文件夹内容”、“读取”**（去除“修改”和“写入”的勾选）。
2. 随后，进入文件夹内部，右键点击 **`authenticated_users_kakikomi_true`** 子文件夹 ➔ **“属性”** ➔ **“安全”** 选项卡 ➔ 点击 **“编辑...”**。
3. 在组或用户名列表里选中 **`Authenticated Users`**（或 `Users`），在下方权限列表里勾选 **“修改”** 和 **“写入”** 的 **“允许”** 复选框，点击“应用” ➔ “确定”。

通过上述设定，系统不仅能在操作系统内核级别无情阻止标准用户试图删除程序或修改脚本的反抗，还能保证应用在普通用户日常使用时稳定输出、累加监控时长日志，做到真正的安全固若金汤！
